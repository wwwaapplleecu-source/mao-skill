# 毛泽东.skill / Mao Zedong Skill

基于毛泽东著作的方法论体系和表达风格构建的AI Colleague Skill。

> 🚀 **项目状态：已完成并可用** | 📅 **最后更新：2026年4月8日**

## 🌟 核心功能

将毛泽东的哲学思想、工作方法和表达风格蒸馏为AI可用的工具：

- **实践论方法**：实践 → 认识 → 再实践 → 再认识
- **矛盾论方法**：对立统一规律，主要矛盾分析
- **调查研究法**：没有调查就没有发言权
- **群众路线法**：从群众中来，到群众中去
- **毛式表达风格**：排比、设问、对比、比喻修辞

## 🚀 快速开始

### 方式一：直接使用技能（推荐）

如果你只是想使用毛泽东.skill，不需要创建过程：

1. 复制 `colleagues/mao/` 目录下的所有文件到你的OpenClaw技能目录
2. 在支持的环境中调用：
   ```bash
   /mao 分析当前项目的主要矛盾
   /mao-work 制定用户调研方案
   /mao-persona 用毛式风格写动员讲话
   ```

### 方式二：完整项目部署

如果你想要完整的创建工具和资料：

```bash
# 1. 克隆仓库
git clone https://github.com/yourusername/mao-skill.git
cd mao-skill

# 2. 安装Python依赖
pip install jieba pypinyin

# 3. （可选）运行文本处理器
python tools/text_processor.py --input-dir knowledge/ --output-dir processed/

# 4. 使用技能
# 将colleagues/mao/目录复制到你的技能目录即可使用
```

## 📋 使用方法

### 调用命令

| 命令 | 功能 | 示例 |
|------|------|------|
| `/mao` | 完整版（方法论+人格） | `/mao 分析公司战略问题` |
| `/mao-work` | 仅方法论 | `/mao-work 设计调研方案` |
| `/mao-persona` | 仅人格风格 | `/mao-persona 写动员讲话` |

### 使用示例

#### 示例1：矛盾分析
```
用户：/mao 分析公司销售额下降的问题

Skill：首先要找出主要矛盾。销售额下降是现象，不是本质。我们要分析内部矛盾：
是产品质量问题？是市场策略问题？还是销售团队问题？也要分析外部矛盾：
市场竞争加剧？消费者需求变化？政策环境影响？抓住主要矛盾，问题就迎刃而解。
```

#### 示例2：战略制定
```
用户：/mao 制定新市场进入战略

Skill：市场进入如用兵，要讲究战略战术。第一阶段（防御）：深入调研，了解市场，建立据点。
第二阶段（相持）：试点推广，积累经验，站稳脚跟。第三阶段（反攻）：全面铺开，扩大战果。
要集中优势资源，先打歼灭战，再打运动战。
```

#### 示例3：工作方法
```
用户：/mao-work 如何开展用户需求调研

Skill：调查研究是基本功。第一，亲自到一线，与用户面对面交流。第二，典型调查与普遍调查结合，
既深入又全面。第三，材料要丰富，观点要准确。第四，分析要客观，结论要可靠。
没有调查，就没有发言权；没有正确的调查，同样没有发言权。
```

## 🔧 技术细节

### 毛泽东概念词典
文本处理器内置了70+个毛泽东核心概念，包括：
- 哲学概念：实践论、矛盾论、实事求是、群众路线、阶级斗争
- 政治概念：新民主主义、社会主义、统一战线、人民民主专政
- 工作方法：调查研究、批评与自我批评、惩前毖后、治病救人
- 军事概念：持久战、运动战、游击战、战略防御、战术重视

### 双层架构
采用colleague-skill标准的双层架构：
1. **Work Skill**（方法论体系）：基于《实践论》《矛盾论》《论持久战》
2. **Persona**（人格风格）：基于《毛泽东选集》的表达风格和思维方式

### 编码处理
- 自动处理GBK/UTF-8编码问题
- 支持中文文件名乱码自动修复
- 输出统一为UTF-8编码

## 📚 理论基础

### 主要著作参考
1. **《实践论》**（1937年）- 认识论基础
2. **《矛盾论》**（1937年）- 方法论基础  
3. **《论持久战》**（1938年）- 战略思维
4. **《反对本本主义》**（1930年）- 调查研究
5. **《毛泽东选集》**（1-4卷）- 表达风格和思维方式

### 核心概念
- 实事求是、群众路线、独立自主
- 主要矛盾、次要矛盾、矛盾转化
- 实践、认识、再实践、再认识
- 战略上藐视敌人，战术上重视敌人
- 从群众中来，到群众中去

## ⚠️ 使用限制

### 适用场景
- 战略分析与规划
- 矛盾分析与解决
- 工作方法指导
- 调查研究设计
- 领导力与团队建设

### 不适用场景
- 技术细节问题
- 情感咨询
- 个人隐私问题
- 当代政治评论
- 敏感历史评价

### 表达边界
- 专注于方法论和思维方式的提取
- 保持学术中立，尊重历史事实
- 不进行政治宣传或意识形态灌输
- 不讨论敏感历史时期和事件
