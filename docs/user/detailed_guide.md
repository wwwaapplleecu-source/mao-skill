## 1. 基本命令

### 1.1 核心命令

#### `/mao [问题]`
**功能**: 使用毛泽东方法论和风格回答问题
**示例**: 
```bash
/mao 分析当前项目的主要矛盾
/mao 如何开展用户调研
/mao 制定团队发展计划
```

#### `/mao-work [问题]`
**功能**: 只使用方法论部分（不包含毛泽东风格）
**适用场景**: 需要纯粹方法论分析时
**示例**:
```bash
/mao-work 分析产品的市场定位
/mao-work 制定项目风险管理策略
```

#### `/mao-persona [问题]`
**功能**: 只使用毛泽东人格风格
**适用场景**: 需要毛泽东式表达时
**示例**:
```bash
/mao-persona 写一段项目动员讲话
/mao-persona 总结本次会议的精神
```

### 1.2 专门分析命令

#### `/mao-analyze 矛盾 [问题]`
**功能**: 专门进行矛盾分析
**核心方法**: 主要矛盾与次要矛盾分析
**示例**:
```bash

/mao-analyze 矛盾 识别团队内部问题
```

#### `/mao-analyze 实践 [问题]`
**功能**: 实践论指导
**核心方法**: 实践-认识-再实践循环
**示例**:
```bash
/mao-analyze 实践 如何改进工作流程
/mao-analyze 实践 制定产品迭代计划
```

#### `/mao-analyze 调查 [问题]`
**功能**: 调查研究方法
**核心方法**: 没有调查就没有发言权
**示例**:
```bash
/mao-analyze 调查 如何了解用户需求
/mao-analyze 调查 开展市场调研的方法
```

#### `/mao-analyze 战略 [问题]`
**功能**: 战略思维指导
**核心方法**: 持久战思维，战略上藐视战术上重视
**示例**:
```bash
/mao-analyze 战略 制定公司三年发展规划
/mao-analyze 战略 应对行业变革的策略
```

#### `/mao-analyze 群众 [问题]`
**功能**: 群众路线方法
**核心方法**: 从群众中来，到群众中去
**示例**:
```bash
/mao-analyze 群众 如何做好团队管理
/mao-analyze 群众 收集员工反馈的方法
```

## 2. 分析方法详解

### 2.1 矛盾分析法

#### 核心原理
- **主要矛盾**: 决定事物性质和发展方向的矛盾
- **次要矛盾**: 影响事物发展的其他矛盾
- **矛盾转化**: 矛盾双方在一定条件下相互转化

#### 应用步骤
1. **识别矛盾**: 找出问题涉及的各种矛盾
2. **区分主次**: 确定主要矛盾和次要矛盾
3. **分析关系**: 分析矛盾双方的对立统一关系
4. **制定对策**: 针对主要矛盾制定解决方案

#### 实际案例
**问题**: 产品用户增长缓慢
**分析**:
```
主要矛盾: 产品功能与用户需求的矛盾
次要矛盾: 市场推广不足、竞争对手强劲、团队资源有限等
对策: 聚焦主要矛盾，优化产品功能匹配用户需求
```

### 2.2 实践论方法

#### 核心原理
- **实践是认识的来源**: 认识从实践中来
- **实践是检验真理的标准**: 认识需要实践检验
- **实践-认识-再实践**: 循环往复，不断提高

#### 应用步骤
1. **实践探索**: 通过实践获取感性认识
2. **总结提升**: 将感性认识上升为理性认识
3. **指导实践**: 用理性认识指导新的实践
4. **循环验证**: 在实践中检验和发展认识

#### 实际案例
**问题**: 如何优化工作流程
**分析**:
```
1. 实践: 尝试新的工作方法
2. 认识: 总结成功经验和失败教训
3. 再实践: 基于总结优化方法，再次实践
4. 再认识: 形成更完善的优化方案
```

### 2.3 调查研究法

#### 核心原理
- **没有调查就没有发言权**: 决策必须基于充分调查
- **正确的调查方法**: 调查要深入、全面、客观
- **调查与研究结合**: 在调查基础上进行研究分析

#### 应用步骤
1. **制定计划**: 明确调查目的、对象、方法
2. **深入实际**: 到一线获取第一手材料
3. **分析研究**: 对调查材料进行分析研究
4. **得出结论**: 基于研究形成可靠结论

#### 实际案例
**问题**: 如何了解用户需求
**分析**:
```
1. 调查: 通过访谈、问卷、观察等方式收集用户数据
2. 研究: 分析用户行为模式、需求痛点、使用习惯
3. 结论: 形成用户需求分析报告，指导产品设计
```

### 2.4 战略思维法

#### 核心原理
- **持久战思维**: 分阶段实施，稳步推进
- **战略上藐视**: 对困难有必胜信心
- **战术上重视**: 具体实施要周密细致

#### 应用步骤
1. **全局分析**: 分析整体形势和环境
2. **阶段划分**: 制定分阶段实施计划
3. **资源集中**: 集中优势资源突破关键点
4. **灵活调整**: 根据形势变化调整策略

#### 实际案例
**问题**: 制定三年发展规划
**分析**:
```
阶段一（防御）: 夯实基础，建立核心能力
阶段二（相持）: 稳步发展，扩大市场份额
阶段三（反攻）: 引领行业，实现跨越发展
```

### 2.5 群众路线法

#### 核心原理
- **从群众中来**: 集中群众的智慧和意见
- **到群众中去**: 将决策转化为群众行动
- **相信群众**: 依靠群众的力量解决问题

#### 应用步骤
1. **深入群众**: 了解群众需求和意见
2. **集中智慧**: 集中群众的正确意见
3. **形成决策**: 将群众意见转化为决策
4. **发动群众**: 带领群众实施决策

#### 实际案例
**问题**: 如何做好团队管理
**分析**:
```
1. 了解团队: 掌握团队成员的需求和困难
2. 集中智慧: 听取团队成员的建议和意见
3. 民主决策: 形成团队共识和行动方案
4. 带领团队: 组织团队实施决策，解决问题
```

## 4. 高级使用技巧

### 4.1 命令组合使用

#### 技巧: 问题分解法
将复杂问题分解为多个子问题，分别使用不同命令分析:
```bash
# 复杂问题: 公司转型战略
/mao-analyze 矛盾 分析公司转型面临的主要矛盾
/mao-analyze 调查 如何调研转型的市场机会
/mao-analyze 战略 制定转型的三年规划
/mao-analyze 实践 如何实施转型第一步
```

#### 技巧: 迭代分析法
通过多次迭代深入分析:
```bash
# 第一轮: 初步分析
/mao 分析产品问题

# 第二轮: 专项分析
/mao-analyze 矛盾 深入分析产品主要矛盾

# 第三轮: 解决方案
/mao-analyze 实践 制定产品改进方案
```

### 4.2 问题提法优化

#### 技巧: 具体化问题
**避免**: "怎么办"
**推荐**: "如何具体开展..."
**示例**:
```bash
# 不好
/mao 项目遇到困难怎么办

# 好
/mao 如何分析项目困难的根本原因
/mao 制定解决项目困难的具体步骤
```

#### 技巧: 情境化描述
提供具体情境信息，获得更精准分析:
```bash
# 基础
/mao 分析团队管理问题

# 优化（提供情境）
/mao 分析一个20人技术团队，成员技术水平参差不齐，如何管理
```

## 5. 常见问题解答

### Q1: 毛泽东.skill与传统AI助手有什么区别？
**A**: 毛泽东.skill专门基于毛泽东的方法论和风格，不仅提供答案，还传授毛泽东的思维方法和工作方法。它强调矛盾分析、实践论、调查研究、战略思维、群众路线等核心方法论。

### Q2: 如何获得更好的回答？
**A**: 
1. **问题具体化**: 不要问"怎么办"，要问"如何具体开展..."
2. **提供情境**: 描述具体情境和背景信息
3. **使用专门命令**: 根据问题类型使用对应的分析命令
4. **迭代分析**: 通过多次提问深入分析

### Q3: 毛泽东.skill适用于哪些场景？
**A**: 
- **战略决策**: 公司战略、产品规划、市场分析
- **问题解决**: 矛盾分析、问题诊断、解决方案制定
- **团队管理**: 团队建设、绩效提升、领导力培养
- **个人发展**: 职业规划、能力提升、学习成长
- **研究学习**: 毛泽东方法论学习、思维训练

### Q4: 如何验证毛泽东.skill分析的准确性？
**A**: 
1. **方法论验证**: 检查分析是否符合毛泽东方法论原理
2. **实践检验**: 将分析结果应用于实践检验效果
3. **专家对比**: 与专业分析结果进行对比
4. **多角度验证**: 从不同角度验证分析结论

### Q5: 可以自定义或扩展毛泽东.skill吗？
**A**: 是的，可以通过以下方式:
1. **知识库扩展**: 添加新的毛泽东著作到知识库
2. **概念词典扩展**: 扩展核心概念体系
3. **模板自定义**: 自定义响应模板和风格
4. **功能开发**: 开发新的分析功能

### Q6: 毛泽东.skill的学习曲线如何？
**A**: 
- **初级阶段**: 掌握基本命令和简单分析（1-2小时）
- **中级阶段**: 熟练使用专门分析命令（1-2天）
