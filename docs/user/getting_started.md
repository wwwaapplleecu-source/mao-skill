# 毛泽东.skill 快速入门指南

## 🎯 简介

毛泽东.skill 是一个基于毛泽东方法论和人格风格的AI智能助手。它能够：
- 运用毛泽东的矛盾分析法、实践论等核心方法论分析问题
- 以毛泽东的语言风格和思维方式进行交流
- 提供基于毛泽东著作的智慧指导
- 帮助用户学习和应用毛泽东的工作方法和领导艺术

## 🚀 快速开始

### 1. 安装与配置

#### 方式一：通过OpenClaw使用
```bash
# 如果尚未安装毛泽东.skill
openclaw skill install mao-skill

# 激活毛泽东.skill
/use mao
```

#### 方式二：直接使用命令
```bash
# 基本使用方法
/mao [你的问题]

# 示例
/mao 分析当前项目的主要矛盾
```

### 2. 核心命令

#### 基本命令
- `/mao [问题]` - 使用毛泽东方法论和风格回答问题
- `/mao-work [问题]` - 只使用方法论部分（不包含风格）
- `/mao-persona [问题]` - 只使用毛泽东人格风格

#### 分析命令
- `/mao-analyze 矛盾 [问题]` - 专门进行矛盾分析
- `/mao-analyze 实践 [问题]` - 实践论指导
- `/mao-analyze 调查 [问题]` - 调查研究方法
- `/mao-analyze 战略 [问题]` - 战略思维指导
- `/mao-analyze 群众 [问题]` - 群众路线方法

#### 工具命令
- `/mao-concepts` - 查看核心概念库
- `/mao-examples` - 查看使用示例
- `/mao-help` - 查看详细帮助
- `/mao-version` - 查看版本信息

## 📖 使用示例

### 示例1：矛盾分析
```
用户：/mao 分析当前项目的主要矛盾

毛泽东.skill：同志们，分析当前项目的主要矛盾，首先要抓住主要矛盾。当前项目的主要矛盾是内部发展与外部环境的矛盾，次要矛盾包括资源分配、人员协调、技术瓶颈等。要促进矛盾向有利方向转化。
```

### 示例2：实践指导
```
用户：/mao 如何开展用户调研

毛泽东.skill：开展用户调研，调查研究是基本功。没有调查就没有发言权。要深入实际，掌握第一手材料，然后才能研究分析。
```

### 示例3：战略规划
```
用户：/mao-analyze 战略 制定长期战略规划

毛泽东.skill：制定长期战略规划要有持久战思维。分三个阶段：防御、相持、反攻。战略上藐视困难，战术上重视困难。集中优势资源，稳步推进。
```

### 示例4：群众工作
```
用户：/mao-analyze 群众 如何做好团队管理

毛泽东.skill：做好团队管理要坚持群众路线。从群众中来，到群众中去。相信群众，依靠群众，服务群众。了解团队需求，集中团队智慧，解决团队困难。
```

## 🎭 理解毛泽东.skill的输出风格

### 1. 方法论特征
- **矛盾分析法**: 区分主要矛盾和次要矛盾
- **实践论思维**: 强调实践-认识-再实践的循环
- **调查研究**: 没有调查就没有发言权
- **群众路线**: 从群众中来，到群众中去
- **战略思维**: 战略上藐视，战术上重视

### 2. 语言风格特征
- **同志们开头**: 常用"同志们，"作为开头
- **排比句式**: 使用"既要...又要...还要..."等排比
- **经典比喻**: 使用"纸老虎"、"解剖麻雀"等毛泽东经典比喻
- **革命术语**: 使用"革命"、"斗争"、"胜利"等术语
- **总结升华**: 在分析后给出总结和升华

### 3. 价值观特征
- **坚持真理**: 实事求是，追求真理
- **服务人民**: 全心全意为人民服务
- **艰苦奋斗**: 提倡艰苦奋斗的精神
- **团结协作**: 强调团结和协作的重要性

## 🔧 高级使用技巧

### 1. 问题提法优化
- **具体化**: 不要问"怎么办"，要问"如何具体开展..."
- **情境化**: 描述具体情境和背景
- **聚焦化**: 一次只问一个核心问题

### 2. 命令组合使用
```bash
# 先进行矛盾分析
/mao-analyze 矛盾 分析项目问题

# 再进行实践指导  
/mao-analyze 实践 制定解决方案

# 最后进行战略规划
/mao-analyze 战略 制定实施计划
```

### 3. 结果解读与运用
- **识别核心观点**: 从响应中提取核心方法论观点
- **结合实际**: 将毛泽东方法论与实际情况结合
- **创造性应用**: 不要机械照搬，要创造性应用
