## 🎯 毛泽东方法论速查

### 矛盾分析法
**核心原则**: 区分主要矛盾和次要矛盾
**应用步骤**:
1. 识别矛盾 → 2. 区分主次 → 3. 分析关系 → 4. 制定对策
**关键概念**: 主要矛盾、次要矛盾、矛盾转化、对立统一

### 实践论方法
**核心原则**: 实践-认识-再实践循环
**应用步骤**:
1. 实践探索 → 2. 总结提升 → 3. 指导实践 → 4. 循环验证
**关键概念**: 实践第一、感性认识、理性认识、真理标准

### 调查研究法
**核心原则**: 没有调查就没有发言权
**应用步骤**:
1. 制定计划 → 2. 深入实际 → 3. 分析研究 → 4. 得出结论
**关键概念**: 第一手材料、周密的调查、正确的调查

### 战略思维法
**核心原则**: 战略上藐视，战术上重视
**应用步骤**:
1. 全局分析 → 2. 阶段划分 → 3. 资源集中 → 4. 灵活调整
**关键概念**: 持久战、三个阶段、集中优势、以逸待劳

### 群众路线法
**核心原则**: 从群众中来，到群众中去
**应用步骤**:
1. 深入群众 → 2. 集中智慧 → 3. 形成决策 → 4. 发动群众
**关键概念**: 相信群众、依靠群众、服务群众、民主集中

## 🔧 高级使用技巧速查

### 命令组合技巧
**问题分解法**:
```bash
# 复杂问题分解
/mao-analyze 矛盾 分析问题根本矛盾
/mao-analyze 调查 收集相关数据信息  
/mao-analyze 战略 制定整体解决方案
/mao-analyze 实践 设计具体实施步骤
```

**迭代分析法**:
```bash
# 逐步深入分析
/mao 初步分析问题
/mao-analyze 矛盾 深入分析主要矛盾
/mao-analyze 实践 制定改进方案
```

### 问题提法技巧
**避免**: "怎么办"、"如何是好"
**推荐**: 
- "如何具体开展..."
- "制定...的具体步骤"
- "分析...的根本原因"
- "从...角度分析..."

### 结果运用技巧
1. **提取核心观点**: 从响应中提取方法论要点
2. **结合实际调整**: 将方法论与实际情况结合
3. **建立知识体系**: 记录分析结论，形成知识库
4. **持续优化应用**: 基于实践反馈优化使用方法
