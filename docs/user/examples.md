## 1. 商业决策场景

### 示例1: 新产品开发决策

**问题**: 分析新产品开发面临的主要矛盾

```bash
# 使用矛盾分析法
/mao-analyze 矛盾 分析新产品开发面临的主要矛盾
```

**预期响应**:
```
分析新产品开发的主要矛盾，首先要抓住主要矛盾。新产品开发的主要矛盾是产品功能与用户需求的矛盾，次要矛盾包括市场竞争、技术实现、资源分配等。要促进矛盾向有利方向转化，就要以用户需求为导向，优化产品功能设计。
```

### 示例2: 市场竞争分析

**问题**: 分析当前市场竞争格局

```bash
# 使用战略思维法
/mao-analyze 战略 分析当前市场竞争格局
```

**预期响应**:
```
分析市场竞争格局要有持久战思维。分三个阶段：防御阶段（巩固现有市场）、相持阶段（寻找突破点）、反攻阶段（扩大市场份额）。战略上藐视竞争对手，战术上重视竞争对手。集中优势资源，稳步推进。
```

### 示例3: 产品迭代规划

**问题**: 如何制定产品迭代计划

```bash
# 使用实践论指导
/mao-analyze 实践 如何制定产品迭代计划
```

**预期响应**:
```
制定产品迭代计划要遵循"实践-认识-再实践"的循环。先小范围试点，获取用户反馈（感性认识）；再总结经验，形成优化方案（理性认识）；最后扩大推广，验证方案效果（再实践）。实践是检验迭代方案的标准。
```

## 4. 学习研究场景

### 示例10: 毛泽东方法论学习

**问题**: 如何学习毛泽东的矛盾分析法

```bash
# 基础方法论学习
/mao 如何学习毛泽东的矛盾分析法
```

**预期响应**:
```
学习矛盾分析法要把握三个要点：一是理解矛盾的基本概念，二是掌握主要矛盾与次要矛盾的区分方法，三是学会矛盾转化的条件分析。要从毛泽东的《矛盾论》原著出发，结合实际问题进行练习。理论学习与实践应用相结合，才能真正掌握。
```

### 示例11: 经典著作研读

**问题**: 如何研读《实践论》

```bash
# 学习方法指导
/mao 如何研读《实践论》
```

**预期响应**:
```
研读《实践论》要把握三个层次：第一层，理解基本概念（实践、认识、真理）；第二层，掌握核心原理（实践是认识的来源、实践是检验真理的标准）；第三层，学会应用方法（实践-认识-再实践循环）。要结合实际工作学习，做到学以致用，用以促学。
```

### 示例12: 方法论对比研究

**问题**: 比较矛盾分析法与实践论的异同

```bash
# 对比分析方法
/mao 比较矛盾分析法与实践论的异同
```

**预期响应**:
```
矛盾分析法与实践论既有联系又有区别。联系在于：都是毛泽东哲学思想的重要组成部分，都强调辩证思维和具体问题具体分析。区别在于：矛盾分析法侧重问题的结构性分析（主次矛盾、矛盾转化），实践论侧重认识的过程性分析（感性认识、理性认识、再实践）。两者可以结合使用，互相补充。
```

## 5. 复杂问题分析

### 示例13: 多维度项目分析

**问题**: 分析一个复杂项目的成功要素

```bash
# 综合分析方法
/mao 分析一个复杂项目的成功要素
```

**预期响应**:
```
分析复杂项目的成功要素要运用毛泽东的系统思维方法。首先要调查研究，掌握项目全貌；然后矛盾分析，找出影响成功的主要矛盾和次要矛盾；接着战略规划，制定分阶段的实施策略；最后实践检验，在实施中调整优化。成功要素包括：明确的战略目标、科学的战术安排、有力的资源保障、有效的群众动员。这些要素相互联系，构成有机整体。
```

### 示例14: 危机应对方案

**问题**: 制定项目危机应对方案

```bash
# 危机应对方法
/mao 制定项目危机应对方案
```

**预期响应**:
```
制定项目危机应对方案要坚持辩证法。既要看到危机的严重性，又要看到转机的可能性；既要考虑短期应急措施，又要谋划长期根本解决；既要依靠领导决策，又要发动群众参与。具体步骤：1.调查研究，摸清危机全貌；2.矛盾分析，抓住危机根源；3.战略部署，制定应对策略；4.实践检验，调整优化方案。在战略上藐视危机，在战术上重视危机。
```
