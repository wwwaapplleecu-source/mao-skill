## 1. 基础使用问题

### Q1: 毛泽东.skill是什么？有什么特点？
**A**: 毛泽东.skill是一个基于毛泽东方法论和人格风格的AI智能助手。其主要特点包括：
- **方法论指导**: 基于毛泽东的矛盾分析法、实践论、调查研究法、战略思维法、群众路线法等核心方法论
- **风格还原**: 模拟毛泽东的表达风格和思维方式
- **实用导向**: 提供可直接应用于实际问题的方法论指导
- **系统完整**: 包含完整的知识体系和概念词典

### Q2: 如何开始使用毛泽东.skill？
**A**: 推荐的学习路径：
1. **快速入门**: 阅读 `getting_started.md`，掌握基本命令
2. **详细学习**: 阅读 `detailed_guide.md`，深入理解方法论
3. **参考实践**: 查看 `examples.md`，学习实际应用示例
4. **快速查阅**: 使用 `cheat_sheet.md`，快速查找命令和方法

### Q3: 有哪些核心命令？如何使用？
**A**: 主要命令包括：
- **基础命令**: `/mao [问题]`, `/mao-work [问题]`, `/mao-persona [问题]`
- **专门分析命令**: `/mao-analyze 矛盾/实践/调查/战略/群众 [问题]`
- **工具命令**: `/mao-concepts`, `/mao-examples`, `/mao-help`, `/mao-version`

详细说明请参考快速参考表 `cheat_sheet.md`。

### Q4: 如何获得更好的回答？
**A**: 以下技巧可以帮助获得更好的回答：
1. **问题具体化**: 不要问"怎么办"，要问"如何具体开展..."
2. **提供情境**: 描述具体情境和背景信息
3. **使用专门命令**: 根据问题类型使用对应的分析命令
4. **迭代分析**: 通过多次提问深入分析问题
5. **组合使用**: 将复杂问题分解为多个子问题分别分析

## 2. 方法论问题

### Q5: 矛盾分析法如何使用？
**A**: 矛盾分析法的使用步骤：
1. **识别矛盾**: 找出问题涉及的各种矛盾
2. **区分主次**: 确定主要矛盾和次要矛盾
3. **分析关系**: 分析矛盾双方的对立统一关系
4. **制定对策**: 针对主要矛盾制定解决方案

示例命令: `/mao-analyze 矛盾 分析问题的主要矛盾`

### Q6: 实践论方法的要点是什么？
**A**: 实践论的核心要点：
- **实践是认识的来源**: 认识从实践中来
- **实践是检验真理的标准**: 认识需要实践检验
- **实践-认识-再实践循环**: 循环往复，不断提高

实践论强调通过实践获取感性认识，总结上升为理性认识，再用理性认识指导新的实践。

### Q7: 调查研究法的关键是什么？
**A**: 调查研究法的关键原则：
- **没有调查就没有发言权**: 决策必须基于充分调查
- **正确的调查方法**: 调查要深入、全面、客观
- **调查与研究结合**: 在调查基础上进行研究分析

调查研究强调亲自到一线获取第一手材料，掌握真实情况。

### Q8: 战略思维法有什么特点？
**A**: 战略思维法的特点：
- **持久战思维**: 分阶段实施，稳步推进
- **战略上藐视**: 对困难有必胜信心
- **战术上重视**: 具体实施要周密细致
- **集中优势**: 集中优势资源突破关键点

适用于长期规划、复杂问题解决等场景。

### Q9: 群众路线法如何应用？
**A**: 群众路线法的应用方法：
1. **深入群众**: 了解群众需求和意见
2. **集中智慧**: 集中群众的正确意见
3. **形成决策**: 将群众意见转化为决策
4. **发动群众**: 带领群众实施决策

适用于团队管理、群众工作、民主决策等场景。

## 3. 技术问题

### Q10: 毛泽东.skill需要什么运行环境？
**A**: 毛泽东.skill的运行环境要求：
- **Python环境**: Python 3.8+
- **依赖库**: jieba, json等标准库
- **操作系统**: Windows/macOS/Linux均可
- **内存要求**: 建议512MB以上内存
- **存储空间**: 约100MB存储空间

### Q11: 如何扩展毛泽东.skill的知识库？
**A**: 扩展知识库的方法：
1. **添加著作**: 将新的毛泽东著作添加到 `knowledge/` 相应目录
2. **运行处理**: 使用文本处理器处理新著作
3. **更新概念**: 运行概念词典更新脚本
4. **验证质量**: 验证内容的准确性和完整性

详细指南请参考 `knowledge/著作内容贡献指南.md`。

### Q12: 可以自定义响应模板吗？
**A**: 可以自定义响应模板：
1. **修改模板文件**: 编辑 `tools/skill_simulator_optimized.py` 中的响应模板
2. **添加新模板**: 在对应的响应类型中添加新的模板
3. **测试验证**: 运行测试套件验证修改效果
4. **提交贡献**: 将修改提交到项目仓库

建议先备份原始文件，再进行调整。

### Q13: 如何验证毛泽东.skill的准确性？
**A**: 验证准确性的方法：
1. **方法论验证**: 检查分析是否符合毛泽东方法论原理
2. **实践检验**: 将分析结果应用于实践检验效果
3. **专家对比**: 与专业分析结果进行对比
4. **多角度验证**: 从不同角度验证分析结论

项目本身也包含测试套件，可用来验证基本功能。
